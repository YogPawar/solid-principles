# solid-principles

<B>Single responsibilities</B> :
A class should have only one reason to change, meaning it should have
single responsibilities.

<B>Open Closed Principle</B> :
Software entities (classes, modules, functions ) should be open for extension and closed for
modification

<B>Liskov Substitution </B> : Subclass should be substitutable for their base
classes without affecting the correctness of the program.
